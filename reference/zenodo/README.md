# FDR26 — Diabetic Retinopathy Grading Benchmark

Reference implementation accompanying the FDR26 dataset paper.

**Dataset:** [10.5281/zenodo.20605487](https://doi.org/10.5281/zenodo.20605487)
— 3,000 fundus images from 1,918 patients, graded on the five-stage ALFEDIAM
scale by expert consensus (Fleiss' κ = 0.85), released with retinal vessel
segmentation masks and patient-level clinical metadata.

## Pipeline

1. **Phase A** — six architectures (ConvNeXt-Tiny, EfficientNetV2-S,
   Swin-Tiny, ViT-B/16, EfficientNet-B7+CAB, DenseNet-121) trained on
   APTOS 2019 under strictly identical conditions.
2. **Phase B** — selection of the best backbone by quadratic weighted kappa.
3. **Ablation** — contribution of the ordinal head, generalized mean pooling
   and multi-scale fusion, isolated on the external corpus.
4. **Phase C** — fine-tuning on FDR26 with five-fold cross-validation grouped
   at the patient level.
5. **Zero-shot** — transferability of APTOS-trained models to FDR26.

## Getting started

```bash
pip install -r requirements.txt
jupyter notebook FDR26_benchmark.ipynb
```

Download FDR26 from Zenodo and APTOS 2019 from Kaggle, then set the five paths
in the **Configuration** cell.

Adjust `BATCH_SIZE` and `ACCUM_STEPS` to the available GPU memory, keeping
their product equal to 16 so that the effective batch size is preserved.

## Notes

- Every stage checks for an existing checkpoint before training, so an
  interrupted run can be resumed without loss.
- All reported metrics derive from out-of-fold predictions covering the
  complete corpus; the LaTeX tables of the paper are generated by the final
  cell rather than transcribed by hand.
- A fixed random seed is set throughout. Results are reproducible under an
  identical hardware and data-loader configuration; changing `NUM_WORKERS`
  alters the augmentation sequence and may shift metrics by about ±0.01 in
  quadratic weighted kappa.
